# Screenmate hackathon recognition

## Application wording

Screenmate placed third globally out of 687 submitted projects at AI Tinkerers' Agents Everywhere Hackathon with OpenAI. Built by Viren Chauhan, it represented Atlanta, the only U.S. chapter among the top three.

## Evidence

The AI Tinkerers winner announcement embedded in Viren Chauhan's LinkedIn post names Sidekick from Hong Kong first, Arto from Paris second, and ScreenMate by Viren Chauhan from Atlanta third. It states 687 submitted projects and 15 global finalists.

Announcement reproduced in the founder's post: https://www.linkedin.com/posts/viren-chauhan-7b1067333_earlier-this-month-i-participated-in-the-activity-7508343721160278016-UEGZ

Project portfolio: https://virenchauhan.com/projects/screenmate

Organizer's event announcement describing the OpenAI collaboration: https://www.linkedin.com/posts/ai-tinkerers_openai-x-ai-tinkerers-agents-everywhere-activity-7500318074558889984-gzRP

## How to use it

Put the placement and competition size in the founder video and application progress section. Use the chapter detail if space allows. The result is evidence of the build receiving external recognition; report user activity, revenue, and retention separately. Describe the event as the hackathon with OpenAI, without implying that OpenAI invested in Screenmate or became a customer.
